# Website learning to deploy (Flask + Python)

## About  
This is a simple dynamic website built for showcasing my projects, skills, and contact form.  
Built using **Flask**, **Python**, and deployed online for real-world use.

## Tech Stack  
- **Backend**: Python (3.10), Flask  
- **Frontend**: HTML, CSS, JavaScript  
- **Database**: MongoDB (for contact form submissions)  
- **Deployment**: Render
- **Version Control**: Git + GitHub  

## Features  
- Home / About section  
- Skills section  
- Projects showcase  
- Contact form that stores data in the database  
- Downloadable resume  
- Responsive design and animations  

## 🧰 Setup Instructions

Follow these steps to run the project locally 👇

### 1️⃣ Clone the Repository 
git clone https://github.com/Ggowda2004/website_deploy.git
cd website_deploy
2️⃣ Create Virtual Environment
Windows:
python -m venv venv
venv\Scripts\activate

Mac/Linux:
python3 -m venv venv
source venv/bin/activate

3️⃣ Install Dependencies
pip install -r requirements.txt

4️⃣ Set Up MongoDB Connection
Create a .env file in the project folder and add your MongoDB connection string:
set it as an environment variable:

5️⃣ Run Flask App
python app.py

Visit 👉 http://127.0.0.1:5000
